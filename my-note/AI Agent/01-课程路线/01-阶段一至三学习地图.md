# Agent 开发课程：阶段一至三学习地图

> 本文只梳理 POPO《Agent开发学习课表》的阶段一至三，并结合课表中链接资料补充各主题的学习边界。

## 总览

| 阶段 | 课时 | 课程 | 目标 |
| --- | ---: | --- | --- |
| 阶段一：认知篇 | 2 | Agent 本质；ReAct 与 CoT | 从 Chatbot 过渡到能自主决策和调用工具的 Agent |
| 阶段二：工具与扩展篇 | 3 | Tool Calling/MCP；Skills；系统操作与沙箱 | 让 Agent 获得可复用、可治理、受隔离的执行能力 |
| 阶段三：核心篇 | 3 | 上下文工程；记忆架构；多轮状态机 | 管理有限上下文、跨会话记忆和可暂停恢复的状态流 |

## 阶段一：认知篇

### 第 1 课：Agent 的本质与技术全景

课表列出的核心点：

- Chatbot 与 Agent 的差别：主动性、决策流和副作用控制。
- Runtime → Framework → Harness 三层技术视角。
- AI Native Agent 与流程驱动型 Agent 的差异。
- 智能体历史和经典范式概览。

链接资料强调：Agent 不是“LLM 加插件”这么简单，而是模型、工具、记忆、自主决策与生产护栏共同构成的系统；Harness 负责把上下文管理、状态持久化、任务规划、工具执行和治理机制装配成可运行系统。详见 [[01-Agent本质与Harness]]。

### 第 2 课：单 Agent 经典范式

课表要求掌握 ReAct 的 Thought → Action → Observation 循环，能够不依赖框架手写基本循环，并了解 Plan-and-Solve、Reflection，以及无限循环和慢速退化的防护。

## 三阶段之间的关系

```text
阶段一：决定 Agent 如何思考和推进任务
                  ↓
阶段二：赋予 Agent 外部行动能力，并限制行动边界
                  ↓
阶段三：让长任务和多轮会话具备连续状态与可控记忆
```

三者不能相互替代：只有推理没有工具，Agent 无法操作外部世界；只有工具没有上下文管理，长任务会被历史和工具结果淹没；只有记忆没有状态机，仍无法可靠暂停、恢复和审计执行流。
